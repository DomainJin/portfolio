# CV

`cv.html` là bản CV nguồn. Sửa trực tiếp file này khi cần cập nhật.

## Xuất ra PDF

1. Mở `cv.html` bằng Chrome / Edge.
2. `Ctrl + P` → Destination: **Save as PDF**.
3. Margins: **None** (CSS đã tự set lề A4 12mm/14mm).
4. Bỏ tick **Headers and footers** (nếu không sẽ có ngày tháng và URL in kèm).
5. Lưu đè lên `public/cv.pdf` để nút "Tải CV" trên portfolio dùng bản mới.

PDF xuất ra giữ text chọn được (ATS đọc được), không phải ảnh scan.
